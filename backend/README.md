El backend de Fake Radar es un servidor de alto rendimiento construido con Python y FastAPI. Su principal función es actuar como puente entre las interfaces de cliente (Web y Extensión) y nuestro potente modelo de Procesamiento de Lenguaje Natural (NLP).

## Tecnologías Principales

- **FastAPI**: Framework web moderno y rápido para construir la API.
- **Uvicorn**: Servidor ASGI ultrarrápido para Python.
- **PyTorch**: Framework de aprendizaje automático utilizado para las inferencias del modelo.
- **Google Cloud Storage (GCS)**: Almacenamiento seguro y escalable para nuestros modelos entrenados.
